Task 01

Connect to CSV & Initialize Tableau Data Source

Time: 4 mins
Sub-task 1.1: Connect to Text File
Open Tableau Public Desktop > Under Connect > To a File, click Text file > Select student_scores.csv.
Sub-task 1.2: Hide Unnamed CSV Row Index Column
In the Data Source grid preview, locate the first column (named F1 or blank integer index) > Click the column dropdown arrow > Select Hide.
Sub-task 1.3: Rename Data Source Connection
Right-click the data source name at top left > Rename to DS_StudentPerformance.
Tableau Hygiene Tip

Hiding redundant raw row indices reduces metadata noise in the Data Pane, ensuring learners focus only on genuine analytical dimensions and measures.

Task 02

Fix Corrupted Study Hours Date Strings & Impute Nulls

Time: 5 mins
Sub-task 2.1: Identify Date-Corrupted Study Hours
In raw CSVs, study hours between 5 and 10 were auto-formatted by Excel into date strings ("05-Oct" or "5-10").
Sub-task 2.2: Create Clean Study Hours Calculated Field
Create calculated field Study_Hours_Clean using CASE or IF to map "05-Oct" -> "5 - 10 Hours", "< 5" -> "< 5 Hours", "> 10" -> "> 10 Hours".
Sub-task 2.3: Clean Ethnic Group & Parent Education Nulls
Create Parent_Educ_Clean = IFNULL([ParentEduc], "Not Specified") and Ethnic_Group_Clean = IFNULL([EthnicGroup], "Unspecified").
Tableau Calculation Formula
Study_Hours_Clean: CASE [WklyStudyHours] WHEN "05-Oct" THEN "5 - 10 Hours" WHEN "5-10" THEN "5 - 10 Hours" WHEN "< 5" THEN "< 5 Hours" WHEN "> 10" THEN "> 10 Hours" ELSE "Not Recorded" END
Task 03

Engineer Composite Academic Scores & Average Grade

Time: 5 mins
Sub-task 3.1: Create Total Composite Score Measure
Create calculated field Total_Score = [MathScore] + [ReadingScore] + [WritingScore] (Max 300).
Sub-task 3.2: Create Overall Average Score Measure
Create calculated field Overall_Avg_Score = ([MathScore] + [ReadingScore] + [WritingScore]) / 3.
Sub-task 3.3: Set Default Number Properties
Right-click Overall_Avg_Score > Default Properties > Number Format > Number (Custom): 1 decimal place.
Academic Measures
Overall_Avg_Score: ([MathScore] + [ReadingScore] + [WritingScore]) / 3.0

Baseline dataset validation: Overall student population average is 67.8 / 100.

Task 04

Create Letter Grades & Pass/Fail Classification

Time: 5 mins
Sub-task 4.1: Create Standard Letter Grade Dimension
Add Letter_Grade: >=90 -> "A (Outstanding)", >=80 -> "B (Above Avg)", >=70 -> "C (Average)", >=60 -> "D (Below Avg)", Else -> "F (Fail)".
Sub-task 4.2: Create Academic Status Boolean
Create Is_Passing = IF [Overall_Avg_Score] >= 60 THEN "Pass" ELSE "At Risk / Fail" END.
Sub-task 4.3: Create Test Prep Status Label
Create Test_Prep_Clean = IF [TestPrep] = "completed" THEN "Completed Prep" ELSE "No Prep Course" END.
Letter Grade Formula
Letter_Grade: IF [Overall_Avg_Score] >= 90 THEN "A (90-100)" ELSEIF [Overall_Avg_Score] >= 80 THEN "B (80-89)" ELSEIF [Overall_Avg_Score] >= 70 THEN "C (70-79)" ELSEIF [Overall_Avg_Score] >= 60 THEN "D (60-69)" ELSE "F (< 60)" END
Task 05

Engineer Tableau Level of Detail (LOD) Benchmark Expressions

Time: 6 mins
Sub-task 5.1: Create Global Fixed Benchmark Score
Create calculated field LOD_Global_Avg_Score = { FIXED : AVG([Overall_Avg_Score]) } to retain the total population benchmark regardless of worksheet filters.
Sub-task 5.2: Create Ethnic Cohort LOD Average
Create calculated field LOD_Ethnic_Avg_Score = { FIXED [Ethnic_Group_Clean] : AVG([Overall_Avg_Score]) }.
Sub-task 5.3: Create Student Performance Delta vs Global
Create Score_Delta_vs_Global = [Overall_Avg_Score] - [LOD_Global_Avg_Score].
Why LOD Expressions?

Level of Detail expressions allow you to calculate values at the data source level without referencing the visualization's dimensional granularity. This keeps national benchmarks steady even when slicing by specific student subgroups.

Sub-task 17.3: Dock in Top Horizontal Slicer Ribbon
Arrange the 4 dropdown slicers horizontally directly beneath the title header inside a unified #1C2541 container.
Slicer Design Standard

Placing compact dropdown slicers in a top horizontal ribbon frees up vertical screen space for charts while keeping filters accessible.

Task 18

Synchronize Slicers Across All Dashboard Worksheets

Time: 5 mins
Sub-task 18.1: Apply Slicer to Related Worksheets
Click dropdown arrow on Ethnic_Group_Clean filter > Apply to Worksheets > Selected Worksheets...
Sub-task 18.2: Check All Dashboard Sheets
Check: BAN_Student_KPIs, Bar_TestPrep_Impact, Heatmap_ParentEduc_Lunch, Scatter_Math_vs_Reading, and Boxplot_StudyHours.
Sub-task 18.3: Repeat for Gender, Prep & Lunch Slicers
Apply all remaining slicers to all dashboard worksheets so any filter change updates the entire dashboard simultaneously.
Slicer Sync Rationale

Without explicit synchronization via "Apply to Worksheets", filter selections only modify a single chart, breaking dashboard analytical consistency.
