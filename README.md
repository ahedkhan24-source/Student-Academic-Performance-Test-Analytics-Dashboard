# Student-Academic-Performance-Test-Analytics-Dashboard
🎓 Student Academic Performance And Test Analytics (Tableau)
📌 Overview

This Tableau dashboard provides an in-depth analysis of student academic performance across various subjects, demographics, and study habits. It evaluates the impact of key socio-economic and behavioral factors—such as parental education level, completion of test preparation courses, lunch types, and weekly study hours—on overall student test scores.

🔑 Key Metrics & KPI Highlights

Total Students Analyzed: 30,641

Average Math Score: 67

Average Writing Score: 68

📊 Visualizations & Insights

Executive KPI Cards: Quick summary displaying total student count alongside average Math and Writing performance scores.

Test Preparation Course Impact: Comparative breakdown of Math, Reading, and Writing scores based on test preparation completion status.

Parental Education & Lunch Matrix: Heatmap matrix evaluating student scores across parental education backgrounds and socio-economic indicators (Standard vs. Free/Reduced lunch).

Study Hours Analysis: Visual distribution evaluating academic performance grouped by weekly study duration (<5 hours, >10 hours, Not Recorded) and segmented by gender.

Correlation Scatter Plot: Regression/scatter analysis illustrating the direct correlation between Math and Reading proficiency scores by gender.

🛠️ Tech Stack & Key Skills

BI Tool: Tableau Public / Tableau Desktop

Visual Techniques: Heatmaps, Stacked Bar Charts, Correlation Scatter Plots, KPI Summary Cards

Domain Focus: Educational Data Analytics, Behavioral Impact Analysis, Performance Benchmarking
